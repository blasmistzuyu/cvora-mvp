CVORA

Privacidad y tratamiento de tu CV

Versión beta. Antes de lanzar un servicio comercial, el responsable deberá completar sus datos de identificación y contacto y revisar esta política conforme a las leyes aplicables.

CVORA Score

La puntuación orientativa compara aspectos observables de estructura y redacción mediante reglas locales del servidor. No es una probabilidad de empleo ni incorpora evaluaciones de reclutadores. El texto utilizado para el cálculo no se conserva en una base de datos de CVORA.

Qué información procesamos

El CV que pegás o subís, el texto de una oferta laboral opcional y el texto que editás para exportar, y tus comentarios y solicitudes de mejora sobre el CV. Pueden contener nombre, correo, teléfono, empleo y educación: evitá datos sensibles que no sean necesarios.

Para qué la usamos

Para extraer texto, brindar una evaluación, redactar y volver a ajustar versiones con IA si lo autorizás y generar descargas PDF/Word.

Almacenamiento

Este MVP no crea cuentas ni una base de datos de currículums. Los archivos se procesan en memoria y no se guardan intencionalmente en el servidor. Los proveedores de infraestructura pueden generar registros técnicos (como IP y hora), según sus condiciones.

IA externa

Cuando está configurada una clave de API y aceptás expresamente, el texto original del CV, el texto revisado, el comentario de mejora y, si existe, la oferta se envían a OpenAI para generar una revisión. CVORA configura store=false para la petición, pero el tratamiento de datos por el proveedor se rige por sus políticas y opciones de retención. Sin autorización, se utiliza un análisis básico local al servidor sin modelo de IA.

Compras (solo si se habilitan)

Al contratar una mejora con IA, CVORA conservará el identificador técnico del pedido y su estado de pago en una base de datos segura para acreditar créditos. Mercado Pago procesará los datos de cobro; CVORA no recibe ni almacena el número completo de tu tarjeta. Los pedidos de prueba están desactivados mientras se completan las condiciones legales y comerciales.

Descargas

El PDF o Word se genera bajo pedido y se envía directamente al navegador. Este MVP no guarda una copia del documento. El historial de ajustes queda solo en la memoria temporal de la página y se pierde al recargarla.

Tus decisiones

Podés no usar la IA, dejar de usar el servicio y no incluir datos que no desees procesar. Para una puesta en producción comercial, habrá que añadir el canal de contacto y los mecanismos legales para ejercer tus derechos.
